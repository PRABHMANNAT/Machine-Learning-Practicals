# Handbook integration map

The handbook was reviewed page by page and its useful teaching material was placed beside the matching bootcamp topics. The additions are separate notebooks so the original lessons remain available and easy to compare.

| Handbook material | Bootcamp location |
|---|---|
| First script, REPL, comments, docstrings, modules, pip | `1-Python Basics/1.4-handbook-companion.ipynb` and `1.5-handbook-syntax-supplement.ipynb` |
| Variables, types, input, strings, `None` | `1-Python Basics/1.1-Variables.ipynb`, `1.2-Datatypes.ipynb`, `1.4-handbook-companion.ipynb` |
| Conditions and loops | `2-Control Flow/2.3-handbook-control-flow-supplement.ipynb` |
| Lists, tuples, dictionaries, sets | `3-Data Structures/3.5-handbook-data-structures-supplement.ipynb` |
| Functions, recursion, lambda, map/filter/reduce | `4-Functions/4.6-handbook-functions-and-projects.ipynb` |
| Snake Water Gun and Perfect Guess projects | `4-Functions/4.6-handbook-functions-and-projects.ipynb` |
| Jarvis voice assistant and auto-reply chatbot project blueprints | `4-Functions/4.7-handbook-project-blueprints.ipynb` |
| Imports, pip, virtual environments, main guard | `5-Modules/5.3-handbook-packages-and-environments.ipynb` |
| Text/binary files, modes, `with`, file exercises | `6-File Handling/6.3-handbook-file-io-supplement.ipynb` |
| try/except/else/finally, raise, validation | `7-Exception Handling/7.2-handbook-exceptions-supplement.ipynb` |
| Classes, attributes, methods, properties, inheritance, dunder methods | `8-Class And Objects/8.8-handbook-oop-supplement.ipynb` |
| Type hints, walrus, match, comprehensions, enumerate, dict merge | `9-Advance Python Concepts/9.4-handbook-modern-python-supplement.ipynb` |
| Handbook Flask/web-server exercise | `13-Flask/13.1-handbook-flask-bridge.md` |

Folders 10-16 cover data analysis, databases, logging, Streamlit, memory, and concurrency. Those subjects are not covered by the handbook, so their notes were left unchanged rather than padded with unrelated material.

## How to study

Read the existing lesson first, then open the handbook supplement in the same folder. Predict every output before running code, and complete the practice section before moving on.
