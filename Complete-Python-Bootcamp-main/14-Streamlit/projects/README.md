# Streamlit mini-projects

These files combine widgets, data, charts, and application logic into small
projects. Run one from the `14-Streamlit` folder, for example:

```powershell
streamlit run projects/dinosaur_classifier.py
streamlit run projects/country_classifier.py
```

`dinosaur_classifier.py` uses scaled nearest-neighbour classification to match
body measurements with one of six example dinosaurs. `country_classifier.py`
matches a coordinate with the closest capital in its ten-country teaching
table. Both are intentionally tiny learning models, not scientific services.
