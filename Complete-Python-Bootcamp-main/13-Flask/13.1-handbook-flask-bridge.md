# Handbook bridge: first Flask server

The handbook's final practice set suggests exploring Flask and creating a web server. This folder already contains small Flask examples; use this note as the connection between the handbook and those files.

## Smallest useful server

```python
from flask import Flask

app = Flask(__name__)

@app.get("/")
def home():
    return "Hello from Python!"

if __name__ == "__main__":
    app.run(debug=True)
```

Run it from this folder with:

```text
python -m pip install flask
python app.py
```

Then open the local address printed by Flask. A route is a function connected to a URL. Keep route functions small and move reusable work into ordinary Python functions.

## Beginner checklist

1. Start with a plain text response.
2. Add a second route such as `/about`.
3. Read a value from a URL or form only after the basic server works.
4. Handle invalid input with clear responses.
5. Turn off `debug=True` when exposing an application publicly.

This is a learning example. Do not put passwords or API keys in the source file.
